# Resource allocation

Budget is rarely the binding constraint. Check the five capacities below before committing a
calendar, and resize the plan to the scarcest one.

## 1. The five capacities

| Capacity              | Typical unit                        | Symptom when overcommitted                      |
| --------------------- | ----------------------------------- | ----------------------------------------------- |
| Creative supply       | assets per variant per channel      | one creative stretched across segments; fatigue  |
| Data & engineering    | integrations, feeds, model refreshes | stale feeds, campaigns launched on old segments |
| Measurement capacity  | concurrent clean holdouts            | contaminated controls, unreadable results       |
| Trade / field         | store visits, planogram changes      | structural changes never land (upstream, not ours) |
| Sub-agent concurrency | parallel briefs in flight           | overlapping scopes, conflicting decisions        |

## 2. Size the ask before delegating

Each brief states its resource ask: creative variants, data dependencies, the measurement design
it consumes, and the field work it requires. A brief that does not fit the period's capacity gets
resized before it is sent, not after it fails.

## 3. Prioritize on value per scarce unit

Rank plays by `expected incremental margin ÷ units of the scarcest resource`, not by budget size.
When measurement capacity is scarce, fund the play whose result changes the most future decisions —
the informational value of a clean read compounds across periods.

## 4. Parallel vs sequential delegation

Delegate in parallel only when scopes are disjoint: different brands, different territories, or
different customer segments. Overlapping scopes must be sequenced, or the results cannot be
attributed to either service. When briefing several sub-agents at once, give each a
non-overlapping write scope and state the boundary in the brief.

## 5. Protect the reserve

Measurement reserve and measurement capacity are not contingency funds. They are not reassigned
to cover an overrun in another service. If the plan cannot be delivered within capacity, cut a
play — never the validation of the plays that remain.
